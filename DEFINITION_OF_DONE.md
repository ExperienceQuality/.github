# Definition of Done

An item is done only when all of the following are true:

1. **Paired.** The artifact is linked to its paired test (see the V column in [`SDLC.md`](./SDLC.md)).
2. **Green.** The paired tests pass.
3. **Approved.** David has approved (including all AI-written code).

No DORA or other metrics gates for now.
